🧭 Campus Compass
Campus Compass is a smart campus navigation app built with Flutter. It helps students, staff, and visitors easily find their way around the university by combining real-time location tracking, intelligent place search, and guided turn-by-turn navigation — all optimized for the campus environment.
🚀 Features
🗺️ Interactive Map Integration — Combines Google Maps and Mapbox for the best of both worlds:
Google Maps for place search, geocoding, and directions.
Mapbox for smooth, turn-by-turn navigation and route visualization.
🔍 Smart Search — Quickly find lecture halls, hostels, cafes, or any campus spot with autocomplete suggestions powered by Google Places API.
📍 Live Location Tracking — See your position update in real time across campus.
🎯 Geo-Fenced Accuracy — Search results are restricted to campus boundaries for more precise navigation.
☁️ PocketBase Backend — Handles data persistence, user profiles, and campus data with a lightweight and efficient backend.
💬 Clean and Intuitive UI — Focused on usability, clarity, and accessibility.
