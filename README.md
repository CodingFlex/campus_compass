🧭 Campus Compass
Campus Compass is a smart campus navigation app built with Flutter. It helps students, staff, and visitors easily find their way around the university using real-time location tracking, intelligent place search, and guided turn-by-turn navigation — all optimized for the campus environment.


###🚀 Features
🗺️ Interactive Map Integration
Combines Google Maps and Mapbox for the best navigation experience:
Google Maps — Place search, geocoding, and directions.
Mapbox — Smooth, real-time turn-by-turn navigation and route visualization.


🔍 Smart Search
Quickly find lecture halls, hostels, cafes, or any campus spot with autocomplete suggestions powered by Google Places API.

📍 Live Location Tracking
See your position update in real time as you move around campus.

🎯 Geo-Fenced Accuracy
Search results are restricted to campus boundaries for precise navigation.

☁️ PocketBase Backend
Handles data persistence, user profiles, and campus information using a lightweight and self-hosted backend.

💬 Clean & Intuitive UI
Focused on usability, clarity, and accessibility for a smooth navigation experience.


###✅ Tech Stack
Flutter + Dart
Google Maps & Places API
Mapbox SDK
PocketBase (Backend)
Stacked Architecture (MVVM)
